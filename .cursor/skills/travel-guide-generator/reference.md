# 旅游攻略生成器 - 参考说明

本文件为 SKILL 执行时的**查表与细则**：必采清单、配色、MD/HTML 模板、地图规则、搜索渠道、检索式、出发前清单、方案对比、每日交互地图实现。执行时以 SKILL 为主、本文件为辅。

## 一、信息收集必采清单（与完成度对应）

用于多轮对话时逐项确认，未填项在「仍缺」中列出。

| 序号 | 字段 | 权重 | 示例/说明 |
|------|------|------|----------|
| 1 | 目的地（国家/城市/地区） | 13% | 如：日本东京+长野、意大利罗马+佛罗伦萨、中国云南 |
| 2 | 出行日期与天数 | 12% | 如：2026年3月13日–17日、共5天 |
| 3 | 出发城市 | 10% | 如：深圳、北京、上海，影响交通方案与路线规划 |
| 4 | 出行季节/月份 | 4% | 如：3月春季、2月冬季，用于配色与穿衣建议 |
| 5 | 偏好类型 | 8% | 美食/人文/自然/购物/亲子/滑雪/海岛等，可多选 |
| 6 | 同行人群 | 5% | 独行/情侣/朋友团/亲子；影响餐厅档次、活动类型、住宿建议 |
| 7 | 预算档次 | 4% | 经济/舒适/轻奢/不设限 |
| 8 | 交通方式与节点 | 9% | 航班、火车、自驾、机场/车站名、是否夜巴等 |
| 9 | 住宿区域或已定酒店 | 4% | 如：罗马中央火车站附近、白马高山酒店 |
| 10 | 必去/必吃清单 | 8% | 景点、餐厅、活动名称 |
| 11 | 禁忌与限制 | 4% | 不吃辣、不去人多、身体限制等 |
| 12 | 特殊需求 | 9% | 签证、退税、防盗、预约、药妆、紧急电话等 |
| 13 | 地图偏好 | 5% | 默认：中国境内→高德，境外→Google |
| 14 | 其他备注 | 5% | 自由补充 |

完成度 = 已明确填写的字段对应权重之和，目标 ≥85% 再进入资料搜集与写作。

## 四、地图链接规则

### 中国境内（高德地图）

- 搜索 URL：`https://uri.amap.com/search?keyword=关键词` 或 `https://www.amap.com/search?query=关键词`
- MD 中：`[地点名](https://uri.amap.com/search?keyword=地点名)`
- HTML 中：`<a href="https://uri.amap.com/search?keyword=地点名" target="_blank" rel="noopener" class="loc">地点名</a>`

### 中国境外（Google 地图）

- 搜索 URL：`https://www.google.com/maps/search/?api=1&query=关键词`
- MD 中：可写「**地点名**」或 `[地点名](https://www.google.com/maps/search/?api=1&query=地点名)`
- HTML 中：使用点击打开新窗口，与现有项目一致：

```html
<span class="loc" onclick="openMap('地点名')">地点名</span>
```

```html
<script>
function openMap(loc){
  window.open('https://www.google.com/maps/search/?api=1&query='+encodeURIComponent(loc),'_blank');
}
</script>
```

若整站均为中国境内，可全部采用高德并统一用 `<a>`；若为境外或混合，境外地点用 `openMap`，境内地点用高德 `<a>`。

## 七、精准检索式建议

按「信息类型」组织关键词，提高命中率与时效性。**所有检索式中的年份一律替换为实际出行年份（如 2026）**，避免检索到过期信息。

| 信息类型 | 检索式示例 | 说明 |
|----------|------------|------|
| 开放时间/门票 | `[景点名] 开放时间 [出行年份]`、`[景点名] 门票 预约` | 带年份减少过期信息 |
| 排队/预约 | `[景点名] 排队 预约`、`[目的地] 免排队 攻略` | 用于写「重要提示」 |
| 餐厅人均/招牌 | `[餐厅名] 人均`、`[目的地] 必吃 餐厅 [出行年份]` | 人均写进最优项 |
| 避坑/注意 | `[目的地] 避坑 [出行年份]`、`[目的地] 注意 防盗`、`[目的地] 踩雷` | 写入提示与时间段注意 |
| 小众/拍照 | `[目的地] 小众`、`[景点名] 拍照 机位` | 备选或拍摄点 |
| 交通时刻 | `[起点] 到 [终点] 火车/大巴`、`[机场] 到 [市区] 交通` | 写入当日交通块 |
| 近期体验 | `[目的地] [出行年份] 游记`、`[目的地] 最近 攻略` | 优先近期 UGC |
| 节假日影响 | `[目的地] [节日名] 人流 攻略`、`[景点名] [节日] 是否限流` | 节假日出行必查 |
| 坐标定位 | 高德地图搜索地点名称→分享/详情页获取 GCJ-02 坐标 | 阶段二同步搜集 |

重要结论尽量**两处来源一致**再写进攻略；不一致可写「约 xxx」「建议出发前在官网确认」。

## 九、HTML 丰富度与可选模块

在保证与现有 snow/anti-theft 结构一致的前提下，**以下「必选」模块阶段四必须实现**，其余为可选增强。

| 模块 | 位置 | 说明 |
|------|------|------|
| **出发前准备清单**（必选） | 重要提示之后、每日行程之前 | 分组：预订项 / 必备 App / 行李 / 证件 / 出发当天 checklist；样式可与 `.tips` 区分或独立 `.prep-checklist` |
| **每日交互地图**（必选） | 每个 `.day-section` 内、`day-header` 下方 | Leaflet.js 实现，规范见**十二**；与当日 time-block 列表**双向联动** |
| **time-block 完成勾选**（必选） | 每个 `.time-block` 顶部或标题行 | `<label><input type="checkbox"> 已完成</label>`；`localStorage` 键名含攻略 slug + dayId + 序号，刷新后保留 |
| **当日高亮**（必选） | 页面 `DOMContentLoaded` | 解析出行日期范围，若「今天」落在某日内，给对应 `.day-section` 加类名（如 `.day-today`）并 `scrollIntoView`（可 `behavior:'smooth'`） |
| **元信息卡片** | 首页副标题下、概览卡片前 | 展示：目的地、出行日期、天数、建议人数/预算区间、标签（美食/人文/自然等）；用 `<table>` 或标签列表，样式与 `.tips` 区分 |
| **交通时刻小表** | 涉及火车/大巴的当日区块内 | 用 `.info-table` 列出车次、发车时间、站点、备注（预约链接等） |
| **预算/花费汇总** | 首页或单独一节 | 可选：总预算区间、按日或按类（交通/住宿/餐饮/门票）粗估；用表格或列表 |
| **紧急联系** | 首页 tips 内或页底 | 报警、使领馆、急救、旅游投诉等；与重要提示统一风格 |
| **图片** | 最优项内或当日头图 | `img/` 下图片，`loading="lazy"`，`alt` 写清说明；无图可占位 `<div class="spot-img placeholder">图位</div>` 或省略 |
| **移动端友好** | 全局 | 按钮与 `.loc` 最小点击区域约 44px；导航 `flex-wrap`；小屏下表格横向滚动或简化为列表；地图容器最小高度约 280px，避免与纵向滚动抢手势 |

可访问性：标题层级连续（h1 → h2 → h3）；关键交互元素可聚焦；色差足够（主色与背景对比度达标）。

## 十二、每日交互地图实现规范（Leaflet.js）

单页 HTML 内实现「序号标记 + 按序连线 + 列表联动 + 一键导航」，**不依赖后端**；底图需联网加载瓦片。

### 12.1 依赖（CDN，版本可锁 1.9.x）

在 `</head>` 前或 `<body>` 末引入：

- Leaflet CSS：`https://unpkg.com/leaflet@1.9.4/dist/leaflet.css`
- Leaflet JS：`https://unpkg.com/leaflet@1.9.4/dist/leaflet.js`
- PolylineDecorator（路线箭头）：`https://cdn.jsdelivr.net/npm/leaflet-polylinedecorator@1.6.0/dist/leaflet.polylineDecorator.js`  
  （若 CDN 不可用，可换 unpkg 同源包路径；无插件时可用纯色 `L.polyline` + 虚线 `dashArray` 作为降级，但**优先**带箭头装饰。）

### 12.2 瓦片图层（按目的地）

- **中国境内（GCJ-02 坐标 + 高德瓦片）**：使用高德矢量/路网瓦片，与子域 `1–4`，示例：  
  `https://webrd0{s}.is.autonavi.com/appmaptile?lang=zh_cn&size=1&scale=1&style=8&x={x}&y={y}&z={z}`，`subdomains: '1234'`，`attribution: '© 高德'`。
- **境外（WGS-84 + OSM）**：`https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png`，`attribution: '© OpenStreetMap'`。
- **混合行程**：按「当日主要活动区域」选一种瓦片；若单日跨境内外，以当日多数停留地为准，并在 SKILL 说明中提示用户境外段以 Google 导航为准。

### 12.3 数据约定（与 MD 坐标一致）

在 HTML 内定义 `window.TRIP_MAP_DAYS`（或同名变量），与阶段三 MD 中 `<!-- coords: [lat, lng] -->` 一致。每日一条：

| 字段 | 说明 |
|------|------|
| `id` | 与 `.day-section` 的 `id` 一致，如 `day-44` |
| `label` | 短标签，如 `4/4 漳州古城` |
| `tileRegion` | `'cn'` 或 `'intl'`，决定瓦片与坐标系 |
| `spots` | 数组，按游览顺序；每项含：`seq`（1 起）、`time`（HH:MM–HH:MM）、`name`、`type`（`food`/`sight`/`transit`/`hotel`/`other`）、`lat`、`lng`、`brief`（一句）、`cost`（可选）、`nav`（高德 `uri.amap.com` 或 Google Maps search URL） |

纯交通段（如「酒店→车站」）若无可代表 POI，可省略该点或合并到相邻段；**地图上只展示有稳定坐标的停留点**，避免折线乱跳。

### 12.4 DOM 约定（联动必备）

- 每个 `.day-section` 内：`<div class="day-map-wrap" data-day-id="day-44"><div id="map-day-44" class="day-map"></div></div>`，**紧接**在 `day-header` 之后。
- 每个 `.time-block`：加 `data-day-id`、**有序号** `data-map-seq="1"`（与 `spots[].seq` 对应）；**有地图点的块**才标序号，无坐标块不标或 `data-map-seq` 留空。
- 页面定义 CSS：`.day-map { height: min(42vh, 420px); min-height: 280px; border-radius: 10px; z-index: 1; }`；小屏保持 `min-height: 280px`。

### 12.5 标记与路线

- 使用 `L.divIcon` 生成**圆形序号**（白底/主色边框/主色数字），`iconSize` 与 `iconAnchor` 居中对齐锚点。
- `type` 可用边框色或小圆点区分（如 `food` 略偏橙、`sight` 略偏蓝），与攻略主色协调。
- `L.polyline(latlngs, { color: var(--accent) 或主色, weight: 3, dashArray: '8 6' })` 连接各点；**顺序按 `seq` 升序**。
- `L.polylineDecorator(polyline, { patterns: [...] })` 使用 `L.Symbol.arrowHead` 或库文档推荐写法，沿折线重复显示箭头表示方向。
- 初始化后对该日 `map.fitBounds(group.getBounds(), { padding: [24, 24] })`；提供「全览」小按钮可再次 `fitBounds`。

### 12.6 交互（必须实现）

- **点击标记**：`popup` 或 `bindPopup` 含：时间、名称、简介、费用（可选）、按钮「导航」→ `window.open(nav, '_blank')`。
- **点击列表 `.time-block`**（带 `data-map-seq`）：`map.setView([lat,lng], Math.max(map.getZoom(), 15))`，并给该块加临时高亮类（如 `.map-focus`），其他块移除。
- **点击标记**：除弹窗外，滚动页面使对应 `.time-block` 进入视口并加 `.map-focus`。
- **「全览」**：仅当日 `fitBounds`。
- 避免滚动穿透：地图容器上可 `leaflet` 默认已处理；若嵌套复杂，给 `.day-map` 加 `touch-action: none` 仅在地图区域（慎用，以实测为准）。

### 12.7 与「已完成」勾选配合

勾选状态不改变地图点位；可选：已完成 `.time-block` 降低不透明度（CSS），与第九节 localStorage 键一致。

### 12.8 降级与声明

- 无网络时底图无法加载：保留列表与「导航」外链；可在地图区显示简短提示「需联网加载地图」。
- 页脚或元信息区保留一句：坐标来自公开地图检索，**出发前请与导航 App 核对**。
